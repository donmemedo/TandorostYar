# Audit register

63 findings from the multi-lens red/blue audit (6 finder agents reading the code). Only 5 findings received an independent skeptic/reproducer verdict (all judged real) before a usage limit stopped the verification stage. The rest were triaged by reading the code directly and, where fixed, are covered by a regression test or a live pen-test check. `F` fixed in this branch, `M` mitigated with a documented residual risk, `O` open or accepted.
